# About The Coast - V8 content update

Upload app.js, index.html and sw.js to the repository root, replacing those files together. The remaining files are the written rules, tests and instructions.

After Vercel deploys, reopen the app and go to More. Select About The Coast inside the Tournament menu. It opens its own page with plain body text and a Back button. Check the page, Back button and official history link on your phone and Mac.

The section is static text. No SQL, database changes, PIN changes or round reset are required. Existing scoring behaviour is unchanged. The package also retains the previously prepared Tee Trivia rule.

The HTML and offline cache now both reference app version 8-final-6.
