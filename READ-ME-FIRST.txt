Writer Cup V8 save-confirmation fix
Prepared 3 September 2026

Current live app was verified as V8, based on GitHub commit 165aa364eee1d1ddfa978deaa2f0461e3e14e13b. This package has NOT been deployed.

What changes
- Scoring stays on the selected hole when saving is queued or cannot be confirmed.
- Automatic progression requires saved golf scores, all applicable NTP/LD results and a fresh read confirming their values.
- Correction holes stay in place; Hole 18 stays in place and only confirms completion after verified saving.
- Repeated Save taps cannot create overlapping saves.
- The final-hole button reads SAVE HOLE 18.
- Existing Standard second-index overrides and Manual Course support remain.

Install
1. Unzip this file.
2. Open https://github.com/benwriter/writer-cup-2026/upload/main
3. Upload app.js to replace the existing root-level app.js, then commit the change. Vercel should deploy it automatically.
4. The included V8_CHANGELOG.md and test-v8-save.js can also be uploaded to the repository root. The .patch file is for code review and is not needed for uploading.
