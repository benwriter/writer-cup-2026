# V5.1 Changelog

## Singles scoring display
- Holes 13–18 remain **hole-by-hole Stableford match play**. No scoring-rule change.
- Each player still enters their gross score.
- Beneath the gross score, the app now shows shots received on that hole and the calculated Stableford points.
- The Stableford line updates immediately while using the + / − controls, before the hole is saved.
- When Daily Handicap is available but gross score is blank, the app still shows the shots received and marks Stableford points as pending.

## Mobile score controls
- Enlarged the + / − buttons to much larger touch targets.
- Enlarged the gross-score input box and font.
- Added touch-action handling to reduce accidental browser zooming when entering scores on a phone.
